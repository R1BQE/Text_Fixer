# NVDA Text Fixer #

Дополнение для NVDA, которое даёт две команды для работы с **выделенным** текстом в любом приложении:

1. **Причесать выделенный текст** — механически исправляет типографические огрехи: делает заглавной первую букву предложения, строки и всего текста; убирает пробелы перед знаками препинания; схлопывает повторяющиеся пробелы.
2. **Переключить раскладку выделенного текста** — преобразует выделенный текст из одной установленной в Windows раскладки клавиатуры в другую (например, `ghbdtn` → `привет`).

Обе команды работают только с выделением, полученным через буфер обмена (`Ctrl+C`/`Ctrl+V`), поэтому не привязаны к конкретному приложению — Word, Блокнот, браузер, Telegram, Discord, VS Code и обычные текстовые поля обрабатываются одинаково, без специального кода под каждое из них.

## Установка ##

1. Скачайте `.nvda-addon` (см. раздел «Сборка» ниже, если собираете сами).
2. Откройте файл — NVDA предложит установить дополнение.
3. Перезапустите NVDA, когда будет предложено.

## Назначение горячих клавиш ##

Дополнение сознательно не назначает горячие клавиши по умолчанию. Назначьте их сами:

1. NVDA-меню → Настройки → Жесты ввода...
2. Найдите категорию **Text Fixer**.
3. Назначьте удобные сочетания для команд «Причесать выделенный текст» и «Переключить раскладку выделенного текста».

## Как это работает ##

- Обе команды сначала проверяют, не находится ли фокус в поле пароля — если да, ничего не делают и сообщают об этом.
- Затем имитируется `Ctrl+C`, буфер обмена читается, текст обрабатывается и через `Ctrl+V` вставляется обратно на место выделения.
- Исходное содержимое буфера обмена (по возможности — во всех форматах, не только текст) сохраняется перед началом и восстанавливается после завершения, даже если во время операции произошла ошибка.
- Отмена стандартным `Ctrl+Z` в целевом приложении работает как обычно — дополнение не создаёт собственную историю отмены.
- Если раскладок установлено больше двух, при переключении раскладки открывается небольшой доступный диалог со списком раскладок (стрелки, Enter, Escape).

## Известные ограничения ##

- **URL и e-mail.** Правила причёсывания применяются механически, без анализа смысла, поэтому в адресах вида `example.com` или `ivan@example.com` буквы после точек тоже могут стать заглавными (например, `Example.Com`). Это осознанный компромисс: дополнение не пытается «угадывать», что перед ним — ссылка или обычный текст.
- **Кавычки как «мягкая» граница предложения.** Первая буква после открывающей кавычки капитализируется (например, `он сказал "привет.` → `Он сказал "Привет.`), даже если кавычка не следует за точкой. Из-за этого слово сразу после закрывающей кавычки внутри одного предложения иногда может быть капитализировано ошибочно — правило простое и не различает открывающие/закрывающие кавычки.
- **AltGr-символы раскладок** (например, немецкое `@`, `€`) не участвуют в преобразовании раскладки — используются только обычная и Shift-раскладки клавиш.
- **Более двух раскладок.** Название раскладки в списке — это локализованное название языка (например, «Русский», «English»), а не точное имя варианта раскладки; если у вас установлено две раскладки одного языка (например, два варианта английской), они будут пронумерованы.
- Если целевое приложение не поддерживает получение/замену выделения через буфер обмена (Ctrl+C/Ctrl+V), дополнение сообщит об ошибке, а не будет пытаться обойти это опасными способами.

## Сборка из исходников ##

Требуется Python 3.13 и [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run scons
```

В корне проекта появится файл `Text_Fixer-<версия>.nvda-addon`, который можно установить в NVDA.

## Тесты ##

Чистая (не зависящая от NVDA/Windows API) логика — причёсывание текста и построение раскладочного соответствия — покрыта unit-тестами:

```
uv run python -m unittest discover -s tests -v
```
