# Changelog

## 2026.8.31.3

Исправление: команды снова не могли прочитать выделенный текст в некоторых приложениях («Не удалось получить выделенный текст» / «Нет выделенного текста»). Чтение из буфера обмена усилено: добавлен запасной вариант для приложений, передающих текст в ANSI-кодировке, увеличено время ожидания ответа приложения на Ctrl+C (с 0.5 до 2.5 секунды) и добавлен повтор чтения на случай отложенной передачи данных.

## 2026.8.31.2

Исправление: аддон не загружался в NVDA 2024.1+ — модуль win32clipboard (pywin32) больше не входит в состав NVDA. Работа с буфером обмена переписана напрямую на системный Win32 API, сохранение и восстановление содержимого буфера сохранены.

## 2026.8.31.1

Исправление: команды теперь отображаются в категории «Text Fixer» в жестах ввода NVDA — горячие клавиши можно назначать. Проверено на NVDA 2026.2.

## 2026.8.31

Первый релиз NVDA Text Fixer.

- Команда «Причесать выделенный текст»: механически исправляет заглавные буквы в начале текста, строк и предложений, убирает пробелы перед знаками препинания, схлопывает повторяющиеся пробелы.
- Команда «Переключить раскладку выделенного текста»: преобразует выделенный текст между установленными раскладками клавиатуры Windows; при более чем двух установленных раскладках открывается доступный диалог выбора.
- Обе команды защищены от работы в полях пароля.
- Полное (по возможности) сохранение и восстановление содержимого буфера обмена вокруг каждой операции.
- Без горячих клавиш по умолчанию — назначаются через NVDA → Настройки → Жесты ввода → категория «Text Fixer».
