# Changelog

## 2026.9.1.3

Исправление: в списке дополнений NVDA теперь показывается короткое название «Text Fixer» вместо длинного описания.

## 2026.9.1.2

Исправление: при выполнении команд больше не открывается микшер звука Windows. Копирование и вставка вводятся через системный API, и если в момент ввода залипшая или зажатая клавиша Win превращала Ctrl+V в Win+Ctrl+V (а это в Windows 11 и есть горячая клавиша микшера), открывался микшер. Теперь перед вводом Ctrl+C/Ctrl+V залипшие Win и Alt сбрасываются, а после ввода возвращаются на место — вводится всегда чистая комбинация.

## 2026.9.1.1

Исправление: копирование и вставка переведены на прямой ввод клавиш через системный API — команды снова работают в приложениях (например, в Telegram), где раньше появлялась ошибка «Не удалось вставить исправленный текст» из-за сбоя в обходе дерева доступности при нажатии Ctrl+C/Ctrl+V.

Переключение раскладки теперь преобразует знаки препинания по физическим клавишам однозначно, а не по совпадению символов. Пример: текст «dfcz? gtnz? vfif», набранный в английской раскладке, превращается в «вася, петя, маша», а не «вася& петя& маша». «@#$%^&» переходит в «"№;%:?» и обратно.

Звуковой сигнал успеха подаётся только после того, как исправленный текст действительно вставлен, — можно сразу продолжать работу.

## 2026.8.31.4

Исправление: команды снова не могли прочитать выделенный текст, если Ctrl+C перехватывается другими дополнениями NVDA или приложениями. Выделенный текст теперь читается напрямую через объектную модель NVDA, без буфера обмена и без нажатия клавиш. Дополнительно поддерживается выделение, отмеченное курсором обзора (NVDA+F9 — начало, перевод курсора — конец): такая отметка читается и применяется как настоящее выделение. Копирование через буфер обмена осталось как запасной вариант.

## 2026.8.31.3

Исправление: команды снова не могли прочитать выделенный текст в некоторых приложениях («Не удалось получить выделенный текст» / «Нет выделенного текста»). Чтение из буфера обмена усилено: добавлен запасной вариант для приложений, передающих текст в ANSI-кодировке, увеличено время ожидания ответа приложения на Ctrl+C (с 0.5 до 2.5 секунды) и добавлен повтор чтения на случай отложенной передачи данных.

## 2026.8.31.2

Исправление: аддон не загружался в NVDA 2024.1+ — модуль win32clipboard (pywin32) больше не входит в состав NVDA. Работа с буфером обмена переписана напрямую на системный Win32 API, сохранение и восстановление содержимого буфера сохранены.

## 2026.8.31.1

Исправление: команды теперь отображаются в категории «Text Fixer» в жестах ввода NVDA — горячие клавиши можно назначать. Проверено на NVDA 2026.2.

## 2026.8.31

Первый релиз NVDA Text Fixer.

- Команда «Причесать выделенный текст»: механически исправляет заглавные буквы в начале текста, строк и предложений, убирает пробелы перед знаками препинания, схлопывает повторяющиеся пробелы.
- Команда «Переключить раскладку выделенного текста»: преобразует выделенный текст между установленными раскладками клавиатуры Windows; при более чем двух установленных раскладках открывается доступный диалог выбора.
- Обе команды защищены от работы в полях пароля.
- Полное (по возможности) сохранение и восстановление содержимого буфера обмена вокруг каждой операции.
- Без горячих клавиш по умолчанию — назначаются через NVDA → Настройки → Жесты ввода → категория «Text Fixer».
