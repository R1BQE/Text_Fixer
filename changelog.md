# Changelog

## 2026.8.31

Первый релиз NVDA Text Fixer.

- Команда «Причесать выделенный текст»: механически исправляет заглавные буквы в начале текста, строк и предложений, убирает пробелы перед знаками препинания, схлопывает повторяющиеся пробелы.
- Команда «Переключить раскладку выделенного текста»: преобразует выделенный текст между установленными раскладками клавиатуры Windows; при более чем двух установленных раскладках открывается доступный диалог выбора.
- Обе команды защищены от работы в полях пароля.
- Полное (по возможности) сохранение и восстановление содержимого буфера обмена вокруг каждой операции.
- Без горячих клавиш по умолчанию — назначаются через NVDA → Настройки → Жесты ввода → категория «Text Fixer».
